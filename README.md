# C++ IOCP Game Server

> 게임 서버 프로그래밍 팀 프로젝트 「Kirby Chess」  
> IOCP 기반 멀티플레이 게임 서버 구현

## 프로젝트 개요

- 개발 기간: 2020.09.26 ~ 2020.12.20
- 개발 환경: Visual Studio 2019
- 언어: C/C++, Lua
- 네트워크: IOCP
- 데이터베이스: MSSQL 2019

IOCP 모델을 기반으로 다수의 플레이어를 처리하는 게임 서버를 구현한
팀 프로젝트입니다.

네트워크 처리뿐만 아니라 플레이어 시야 관리, 전투 및 충돌 처리,
Lua Script 기반 몬스터 AI, DB 저장/로드 등을 구현했습니다.

## 주요 구현 내용

### IOCP 기반 서버 프레임워크

- IOCP 모델을 이용한 게임 서버 프레임워크 구현
- Overlapped I/O 기반 네트워크 처리
- 다수 클라이언트 접속 처리를 위한 서버 구조 구성
- 테스트 클라이언트를 이용한 동시 접속 테스트

### 멀티스레드 및 동시성 처리

- 멀티스레드 환경에서 게임 서버 로직 처리
- 공유 데이터 접근 시 `Mutex Lock`을 이용한 Data Race 방지
- 동시 접속 처리 과정의 병목 개선을 위해 일부 처리를 CAS 방식으로 변경
- 멀티스레드 관련 문제 분석 및 디버깅

### 플레이어 시야 처리

- Sector 기반 공간 분할
- View List를 이용한 플레이어 시야 관리
- Sectoring 구조 최적화

### 게임 콘텐츠

- 오브젝트 간 전투 및 충돌 처리
- 장애물을 고려한 플레이어 이동
- 몬스터 유형 구현
  - Aggro
  - Roaming
- 전투 메시지 처리

### Lua 기반 몬스터 AI

- Lua Script를 이용한 NPC/Monster AI 구현

### DB

- MSSQL 2019 사용
- Stored Procedure를 이용한 데이터 저장/로드
